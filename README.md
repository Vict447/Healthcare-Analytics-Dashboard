🏥 Healthcare Analytics Dashboard (Excel)
Overview
This project presents a Healthcare Analytics Dashboard built in Microsoft Excel to analyze patient demographics, diagnosis patterns, length of stay, billing performance, and doctor workload.
The dashboard provides a clear, interactive view of key hospital metrics to support operational, financial, and clinical decision‑making.

Key Features
Patient demographics (age, gender, region)

Diagnosis and condition distribution

Length of Stay (LOS) analysis

Billing and revenue trends

Doctor workload and patient allocation

Interactive slicers for dynamic filtering

Clean, professional dashboard layout

Dataset
The dataset includes the following fields:

Patient ID

Gender

Age

Diagnosis / Condition

Admission Date

Discharge Date

Length of Stay

Billing Amount

Doctor Assigned
Analysis
The dashboard highlights key operational and clinical insights across the hospital:

Diagnosis Trends: Certain medical conditions appear more frequently, indicating areas where resources may need reinforcement.

Length of Stay: Some conditions are associated with longer hospital stays, affecting bed availability and patient flow.

Billing Performance: Billing amounts vary across diagnosis categories, reflecting differences in treatment complexity and resource usage.

Doctor Workload: Patient distribution across doctors is uneven, suggesting potential staffing imbalances.

Demographic Patterns: Age and gender groups show distinct diagnosis trends, helping identify vulnerable populations.

These insights help hospital administrators understand performance, identify bottlenecks, and improve service delivery.

Recommendations
Based on the analysis, the following actions are recommended:

Optimize Resource Allocation: Increase staffing or equipment in departments handling high‑volume or high‑LOS conditions.

Balance Doctor Workload: Adjust patient assignment or scheduling to reduce overload on specific doctors.

Improve Patient Flow: Investigate conditions with long LOS to identify opportunities for faster diagnosis, treatment, or discharge.

Strengthen Financial Planning: Use billing trends to forecast revenue and identify high‑cost treatment areas.

Targeted Patient Programs: Develop preventive or early‑intervention programs for demographic groups with high admission rates.

Continuous Monitoring: Refresh the dashboard regularly to track changes and measure improvements.
Summary
This dashboard provides a clear, data‑driven view of hospital operations and patient trends.
It supports better decision‑making by highlighting key insights in patient care, resource utilization, and financial performance.
